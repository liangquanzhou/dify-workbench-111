# 0.4.1 路由表存取节点修复

## 原因与行为

0.4.0 未识别 hu8627/dmn_json/dmn_json 的 route_table_store。0.4.1 支持此节点；变量输入不推测展开。显式点击“读取上次运行（只读）”后，通过同源 GET last-run 读取已有记录。也可导入 result_json 或完整已保存 JSON。

表体必须通过表名、保存版本和 Python 原始数值摘要校验。when_any 保留组内 AND、组间 OR；完整模板和字典可展开。标明历史来源、记录 ID、时间、版本和摘要；历史记录不代表当前配置或存储最新版。读取失败或切换节点会清除旧表。不运行维护节点，不执行 save。

## 验证

隔离原版 Dify 1.11.1，实际安装的 hu8627/dmn_json 0.5.18，独立 Chrome for Testing profile 实际加载 MV3；选择真实节点，调用 Chrome Extensions.triggerAction 激活工具栏。用原创/既有本地合成测试数据，不访问公司 Dify。

11 项真实检查覆盖：MV3 加载、变量存取节点识别、读取前无伪造表、真实记录表体/版本/摘要、三组 OR 条件和历史标签、完整文档/模板、一次明确 GET、无节点运行 POST、切换清表、配置及记录 ID 不变、无页面 JS 异常。8 项新增自动回归覆盖失败响应、篡改、权限错误、大小限制、异步切换及定制路径约束。原有 0.4.0 存储查询、内联和版本约束也回归。

## 限制

公司定制部署未验收。AgentHub 只接受页面已经请求过的、当前应用和节点的同源精确 last-run 路径；需先打开节点“上次运行”。缺此路径时不猜接口，提示导入 JSON。无记录、无查看权限、history 版本列表或无完整表体时不能展示决策表。历史结果读取不替代实时存储查询；后者仍需审核后的只读查询应用。

未更改公司工作流、网站权限或日常浏览器扩展。隔离测试后停止实例。旧归档仓库不会收到此修复；应使用 dify-workbench-111 的构建或发布包。
