# 安装浏览器预览 0.4.4

本次更新的是浏览器扩展，**不能把 ZIP 上传到 Dify 插件管理页**。它不会更新或替换 Brian 的 hu8627/dmn_json 插件，也不会修改 Dify Web 服务端。

1. 获取仓库的 browser-extension/dist/extension 目录。若使用单独提供的 dmn-browser-preview-0.4.4.zip，请核对 SHA256SUMS.txt 后解压。
2. 在组织允许的浏览器扩展安装方式下加载此目录。使用开发者模式加载解压扩展时，按浏览器/组织要求批准；已有旧版加载目录可替换文件后重新加载。
3. 刷新 Dify 工作流页面，点击扩展图标，再点击 DMN 节点。内联 JSON、definition bundle 或 XML 可直接预览。刷新或切换编辑应用后需再次启用。
4. 存储节点的表体不在页面内。可以导入已保存 JSON，或由维护者配置下述只读查询应用。

## 阅读视图与窗口大小

默认用三列展示规则、条件要求、输出声明。AND 表示同时满足，OR 表示任意分组满足；保留规则顺序、路径段、值类型和模板标识。模板是声明，引用尚未解析，预览不会求值或执行动作。路由等配置记录单独标识，不当作可执行规则。超过六项的条件组折叠，展开可看全部。

可切换“矩阵视图”。展开源规则、逻辑表达式或完整文档可看原文；规则 ID 和业务字段不会擅自翻译。列宽在各视图独立保留。

拖动窗口任一边或角调整尺寸，右下角有拖拽标记。“展开”铺满视口，“还原”恢复自定义尺寸。方向键可微调边界，Esc 取消拖拽。窗口不会超出视口；尺寸仅在当前面板会话保留，不写入工作流。

## 拖动调整列宽

拖动表头右侧边界即可调整列宽，表头与正文同步。双击边界还原；Tab 聚焦后可用左右方向键微调，Shift 加方向键每次 50px。列宽最小 100px、最大 1600px；超出面板时横向滚动。翻页保留，切换节点、模型或重新读取后重置，不改工作流数据。

## v0.5.19 兼容

内联 evaluate_decision 和存储模型支持每条规则最多 128 组 when_any，每组最多 32 个条件。保留组内 AND、组间 OR、规则顺序和模板。内联定义包支持 1 MiB，超限明确拒绝。from_table 作为模型来源约束展示，修改后摘要也会变化。

## 路由表存取节点（保留 0.4.1 修复）

0.4.0 遗漏了 Brian 的 route_table_store，因此会显示“此工具不提供可直接预览的决策表”。从 0.4.1 起已识别此节点。它常用运行时变量，配置页没有完整表体。

点击扩展中的“读取上次运行（只读）”，读取已有记录。不会运行节点、保存表或产生新工作流运行。展示的是历史快照，带运行 ID、时间、表名、版本和摘要，不代表当前存储最新版。

原版 Dify 使用同源 GET last-run。定制页面先打开节点的“上次运行”，让页面自身请求该节点记录，再点击扩展读取；扩展只接受已观察到的同源精确接口，不猜接口路径。如果页面接口不同、没有记录或无查看权限，可导出已有结果里的 result_json 为 JSON 文件，再在面板导入。不要为预览执行 op=save。

history 结果只有版本列表，不能显示完整表。结果缺表体、摘要不符或静态表名/指定版本不符时明确报错。当前公司定制页面的实际接口尚未验收。

浏览器当前若加载归档旧仓库内的目录，旧仓库 pull 不会取得此修复。下载本版本 ZIP，解压到独立目录，并按组织允许的方式加载；或在 dify-workbench-111/browser-extension 构建后加载 dist/extension。不要同时启用两个预览扩展。扩展重新加载后刷新 Dify 页面并再次启用。

## 自动读取存储表

维护者在**同租户、同插件身份**下导入 reader-latest.yml 和 reader-version.yml。将每个模板的 REPLACE_TABLE_NAME 改为允许读取的固定表名，再审核发布。模板不提供 op/table/body_json 输入；调用者只可传版本号。

使用组织现有的应用访问控制，让需要看表的人能调用查询应用，但不能修改查询图。不要照搬本地合成测试的匿名访问，不要提供管理员或 Service API key。

维护者按 reader-connections.example.json 填写：当前 Dify origin、编辑应用 UUID、表名、查询应用 site code/readAppId、已发布 workflow UUID。它们是绑定信息，不应填写任何口令或 token。模板中的插件依赖固定到验证过的 Brian 0.5.19 预发布包；已配置的旧查询应用不必重复导入，维护者应核对实际插件版本与访问控制。

在扩展面板选择连接文件，点击“启用查询与自动读取”。随后同一编辑应用内切换节点会自动查询并核对表名、版本与摘要；关闭面板、刷新或换应用后连接失效。

查询会运行专用工作流并产生记录，不运行当前业务节点。维护者必须保持查询图只读。扩展在运行后核对发布版本，变更会拒绝展示，但不能撤销已经发生的执行。

只有摘要、没有版本号的节点目前只核对当前版本，不搜索历史 50 版。身份交换失败、无表体、版本或摘要不符都会报错，不改走编辑接口或回退到其他版本。

## 验证边界

原版 Dify 1.11.1、Brian 0.5.19 和真实 MV3 的隔离链 53 项检查通过；0.5.18 旧版回归也已验证。测试使用仅限一次性本地实例的签名例外，不是关闭公司签名校验的建议。定制部署的 SSO、存储分域、API 路径及权限需在目标环境确认。

本次交付位于 dify-workbench-111 仓库。其现有 CLI/MCP 功能保留；不附带自制 Dify DMN 插件。查询模板是普通 Dify 工作流，调用已安装的 Brian 插件，不需要安装新的 .difypkg。
