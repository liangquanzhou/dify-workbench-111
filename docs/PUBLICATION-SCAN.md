# 公开发布前检查范围

检查日期：2026-09-30 UTC。对象是明确白名单内的发布文件及重新生成的源码 ZIP，而不是开发目录里的所有文件。

## 处理

- 将使用者特定的生成脚本/产物相对路径示例替换为通用合成示例
- 泛化文档与提示中的特定业务内核称呼
- 保留上游 Apache-2.0 LICENSE、NOTICE、固定提交和目标版本来源
- 不复制或推送开发目录的 git 历史；发布 payload 是新的纯文本文件树
- 显式排除 .git、node_modules、本地 state、.env、cookie文件、日志、临时报告和安装缓存
- 保留 package-lock.json、源码校验清单和公开依赖审计摘要

## 扫描类别

检查了私钥头、常见提供商token/JWT模式、凭据文件、Cookie/session数据、账号/email、公司域名、个人电脑绝对路径、真实case与业务源码、用户项目特定路径，以及文本/二进制和ZIP路径安全。

未发现待发布树含真实凭据、个人账号、公司域名、公司代码或真实case。测试中的token/cookie/email均为明确的合成占位；上游文档中的公开项目和服务地址保留。所有发布文件均为UTF-8文本，不含二进制。

扫描结论只覆盖此份明确清单，不能证明任意将来改动或运行时产物没有秘密。不要直接 `git add .` 上传开发目录。提交新fixture或报告前仍需人工审查；DSL、节点错误和业务输入输出即使没有密码字段也可能敏感。

源码 ZIP 内 SOURCE-MANIFEST.sha256 可核对每个发布文件的内容；安装与使用范围见 README 和 VALIDATION.md。
